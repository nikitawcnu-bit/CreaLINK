# CreaLink

**CreaLink** is an open-source game creation platform and 3D engine built with Rust, Macroquad and Rhai.

Create 3D worlds, build scenes, test them in Play Mode, and script your games with Rhai.

## ✨ Features

- 🧱 3D building and scene editing
- 🎮 Play Mode
- 🖱️ Object selection and editor camera
- 💾 Project saving and loading
- 📜 Rhai scripting
- 🎨 Customizable interface themes
- 🦀 Built with Rust
- ⚡ Powered by Macroquad
- 🔓 Open-source

## 📥 Download

You can download the latest Windows build from the
**[Releases](../../releases)** page.

Download `CreaLink.exe` and launch it.
